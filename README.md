# 🎬 ClipForge

**Open-source AI tool to turn long videos into viral Shorts — 100% free, no API fees.**

## ✨ Features
- Auto-detect best moments (hook, climax, emotion)
- Add captions & vertical edit
- Works offline
- MIT Licensed
